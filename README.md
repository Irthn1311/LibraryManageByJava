# Library Management System

A Java Swing desktop application created as academic coursework to manage common library operations.

## Features

- Book catalog management
- Reader / member records
- Employee management
- Borrow and return workflows
- Late-return / penalty logic
- Book intake and supplier-related workflows
- Statistics and reports

## Tech stack

Java · Java Swing · SQL Server · JDBC · NetBeans / Apache Ant

## Project scope

The repository demonstrates a conventional desktop CRUD application with a graphical interface and relational-database integration. It covers the end-to-end flow from UI forms to data-access logic for common library operations.

## Run locally

Open the Ant/NetBeans project, configure the local SQL Server connection expected by the application, and run the main Java entry point.
